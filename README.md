# Smart Tutorials (Samana, Punjab)

Official website for **Smart Tutorials**, located in Samana, District Patiala, Punjab.

A high-performance, conversion-oriented website built with **Astro 5** and **Tailwind CSS**, designed specifically for local and regional student engagement.

---

## 🎓 Core Offerings & Verticals

1. **IELTS & PTE Academic Coaching**:
   - Spoken English and 1-on-1 speaking cabins
   - Computerized PTE software mock test lab
   - Daily grammar clinics & vocabulary builders
2. **Study & Visitor Visa Filing**:
   - Transparent profile evaluation for Canada (SDS), Australia, UK & Europe
   - Complete SOP drafting and refusal re-filing
3. **Air Hostess & Aviation Training**:
   - Airline grooming, etiquette, and confidence building
   - Mock airline interview preparation for domestic & international carriers
   - Airport ground staff and hospitality operations
4. **Computer & AI Courses**:
   - Office productivity: MS Office, Tally Prime with GST, Typing certifications
   - Modern AI tools and practical workflows

---

## 🛠️ Tech Stack & Architecture

- **Framework**: [Astro 5](https://astro.build/) (Static Site Generation / Zero JS default)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Typography**: Plus Jakarta Sans (Google Fonts)
- **Deployment & CI/CD**: GitHub Actions $\to$ GitHub Pages / Cloudflare Pages

---

## 🚀 Quick Start (Local Development)

```bash
# 1. Clone repository
git clone https://github.com/Sukhman369/smarttutorial.git
cd smarttutorial

# 2. Install dependencies
npm install

# 3. Start local development server
npm run dev

# 4. Build for production
npm run build

# 5. Preview production build locally
npm run preview
```
